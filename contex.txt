An AI-powered browser extension that acts as an automated security hygiene auditor for everyday users.

Instead of performing complex offensive penetration tests (which are dangerous and hard to scope for a hackathon), the tool inspects public security posture signals, identifies missing defense standards, and explains risks in simple language.

Key Features
Security Header & Configuration Auditor

Inspects public HTTP response headers to see if standard security protections are active (e.g., Strict-Transport-Security, Content-Security-Policy, X-Frame-Options).

Highlights basic web posture gaps in plain English (e.g., "Missing framing protection — this site could be vulnerable to clickjacking").

Phishing & Homograph Attack Detector

Checks domain age (via public WHOIS metadata), SSL/TLS certificate validity, and character anomalies (typosquatting like g00gle.com).

Warns users before they interact with newly created or suspicious lookalike domains.

Plain-English "Safety Scorecard"

Translates technical header logs and domain metrics into a clean 0–100 Security Health Score.

An LOCAL AI LLM (llama3.2:3b model) summarizes why a site got that score and gives actionable advice (e.g., "Safe to browse, but avoid submitting payment info because SSL configuration is outdated").

Sensitive Input Guard

Detects if a user is about to type passwords or credit card info into unencrypted (http://) or untrusted forms and shows a warning banner.

Recommended MVP (Hackathon Scope)

To keep the project achievable while still impressive, focus on these capabilities:

Analyze HTTPS, TLS, and common security headers.
Detect suspicious URLs using heuristics (homograph characters, excessive subdomains, IP-based URLs, newly registered domains where available).
Check URL reputation using Google Safe Browsing or VirusTotal.
Detect password and payment forms and warn on unsafe pages.
Generate a Security Health Score (0–100).
Use a local Llama 3.2:3B model through Ollama to produce plain-English explanations.
Provide a clean popup dashboard with the score, findings, and recommended actions.

This MVP is realistic to build in a hackathon, demonstrates AI in a meaningful way, and can be extended later with history, educational features, enterprise policies, and more advanced reputation analysis.
